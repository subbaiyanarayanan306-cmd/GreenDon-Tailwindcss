🌿 Reendon Plant Project

A simple and responsive plant-themed website built using HTML and Tailwind CSS. This project showcases a modern UI design for a plant store or gardening website, focusing on clean layout, responsiveness, and reusable components.

📌 Features
🌱 Responsive design for all devices
🎨 Styled using Tailwind CSS utility classes
🪴 Clean and modern plant-themed UI
⚡ Fast loading and lightweight
📱 Mobile-friendly layout
🛠️ Technologies Used
HTML5
Tailwind CSS (via CDN or build setup)
